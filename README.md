# Andrew L. Portfolio

## Run locally

Install Node.js 24 LTS (includes npm), then open a new terminal:

```powershell
cd C:\Andrew.L_Portfolio
npm ci
npm run dev
```

Open http://localhost:3000. Stop the server with `Ctrl+C`.

Dependencies only need installing after cloning the project or changing the lockfile. No environment variables or API keys are required for local development.

## Checks

```powershell
npm run lint
npm run build
```
